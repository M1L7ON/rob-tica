PROYECTO 01 · NIVEL INICIAL

Robot evasor de obstáculos

Construye un vehículo que observa el entorno con ultrasonido y toma decisiones automáticas para evitar colisiones.

INTRODUCCIÓN

¿Qué aprenderás y cómo funciona?

Aprendizaje

Medir distancias, controlar motores, utilizar condiciones y coordinar sensor, servo y movimiento.

Funcionamiento

El HC-SR04 envía un pulso, escucha el eco y calcula la distancia. Si hay un objeto cerca, el robot se detiene, observa los lados y gira hacia el camino libre.

MATERIALES

Componentes necesarios

ENSAMBLAJE

Construcción paso a paso

  1. Fija los dos motores y las ruedas al chasis.
  2. Instala la rueda loca y verifica el equilibrio.
  3. Sujeta Arduino, el controlador y la batería.
  4. Monta el HC-SR04 sobre el servomotor al frente.
  5. Conecta con la batería apagada y ordena los cables.
  6. Comprueba que ninguna pieza bloquee las ruedas.

PROGRAMACIÓN

Código Arduino completo

#include <Servo.h>

// ROBOT EVASOR DE OBSTÁCULOS - ARDUINO NANO
// HC-SR04: TRIG D2, ECHO D3
// Motor izquierdo: D4 y D5
// Motor derecho: D6 y D7
// Servo: señal D9

const byte TRIG = 2;
const byte ECHO = 3;
const byte MOTOR_IZQ_1 = 4;
const byte MOTOR_IZQ_2 = 5;
const byte MOTOR_DER_1 = 6;
const byte MOTOR_DER_2 = 7;
const byte PIN_SERVO = 9;

const int DISTANCIA_SEGURA = 30;
const int CENTRO = 90;
const int IZQUIERDA = 160;
const int DERECHA = 20;

Servo cabeza;

void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(MOTOR_IZQ_1, OUTPUT);
  pinMode(MOTOR_IZQ_2, OUTPUT);
  pinMode(MOTOR_DER_1, OUTPUT);
  pinMode(MOTOR_DER_2, OUTPUT);
  cabeza.attach(PIN_SERVO);
  cabeza.write(CENTRO);
  detener();
  delay(1000);
}

void loop() {
  cabeza.write(CENTRO);
  int distanciaFrente = medirDistancia();

  if (distanciaFrente > DISTANCIA_SEGURA) {
    adelante();
  } else {
    detener();
    delay(250);
    atras();
    delay(350);
    detener();
    delay(200);

    cabeza.write(IZQUIERDA);
    delay(500);
    int distanciaIzquierda = medirDistancia();

    cabeza.write(DERECHA);
    delay(500);
    int distanciaDerecha = medirDistancia();

    cabeza.write(CENTRO);
    delay(300);

    if (distanciaIzquierda > distanciaDerecha) {
      girarIzquierda();
      delay(500);
    } else if (distanciaDerecha > distanciaIzquierda) {
      girarDerecha();
      delay(500);
    } else {
      girarDerecha();
      delay(600);
    }

    detener();
    delay(150);
    cabeza.write(CENTRO);
  }
}

int medirDistancia() {
  long suma = 0;
  int medicionesValidas = 0;

  for (int i = 0; i < 3; i++) {
    digitalWrite(TRIG, LOW);
    delayMicroseconds(3);
    digitalWrite(TRIG, HIGH);
    delayMicroseconds(10);
    digitalWrite(TRIG, LOW);

    long duracion = pulseIn(ECHO, HIGH, 25000);
    if (duracion > 0) {
      int distancia = duracion * 0.0343 / 2;
      if (distancia > 2 && distancia < 400) {
        suma += distancia;
        medicionesValidas++;
      }
    }
    delay(20);
  }

  if (medicionesValidas == 0) return 400;
  return suma / medicionesValidas;
}

void adelante() {
  digitalWrite(MOTOR_IZQ_1, HIGH);
  digitalWrite(MOTOR_IZQ_2, LOW);
  digitalWrite(MOTOR_DER_1, HIGH);
  digitalWrite(MOTOR_DER_2, LOW);
}

void atras() {
  digitalWrite(MOTOR_IZQ_1, LOW);
  digitalWrite(MOTOR_IZQ_2, HIGH);
  digitalWrite(MOTOR_DER_1, LOW);
  digitalWrite(MOTOR_DER_2, HIGH);
}

void girarIzquierda() {
  digitalWrite(MOTOR_IZQ_1, LOW);
  digitalWrite(MOTOR_IZQ_2, HIGH);
  digitalWrite(MOTOR_DER_1, HIGH);
  digitalWrite(MOTOR_DER_2, LOW);
}

void girarDerecha() {
  digitalWrite(MOTOR_IZQ_1, HIGH);
  digitalWrite(MOTOR_IZQ_2, LOW);
  digitalWrite(MOTOR_DER_1, LOW);
  digitalWrite(MOTOR_DER_2, HIGH);
}

void detener() {
  digitalWrite(MOTOR_IZQ_1, LOW);
  digitalWrite(MOTOR_IZQ_2, LOW);
  digitalWrite(MOTOR_DER_1, LOW);
  digitalWrite(MOTOR_DER_2, LOW);
}

PRUEBA FINAL

Evaluación y errores frecuentes

  1. Prueba primero los motores con el robot elevado.
  2. Verifica la distancia en el monitor serial.
  3. Coloca obstáculos y ajusta el límite de 20 cm.
  4. Completa un recorrido sin colisiones.
El sensor siempre marca cero

Revisa VCC, GND, TRIG, ECHO y los números de pin del programa.

Un motor gira al revés

Intercambia sus dos cables o invierte la lógica de esa salida.

Arduino se reinicia al mover los motores

Revisa la alimentación, la batería y la tierra común; los motores no deben alimentarse desde un pin del Arduino.

PROYECTO 02 · NIVEL INTERMEDIO

Robot seguidor de línea

Construye un robot que reconoce una pista y corrige continuamente su dirección.

INTRODUCCIÓN

¿Qué aprenderás y cómo funciona?

Aprendizaje

Interpretar sensores infrarrojos, calibrar claro y oscuro, controlar velocidad PWM y aplicar lógica de corrección.

Funcionamiento

Los TCRT5000 miden la luz reflejada por el suelo. Arduino compara sus lecturas y acelera o frena cada motor para mantener el robot sobre la línea.

MATERIALES

Componentes necesarios

ENSAMBLAJE

Construcción paso a paso

  1. Monta motores, ruedas y apoyo delantero.
  2. Coloca los sensores al frente, paralelos al suelo.
  3. Mantén igual altura y separación entre sensores.
  4. Fija Arduino, L298 y batería.
  5. Conecta el circuito con la batería apagada.
  6. Calibra cada sensor sobre blanco y negro.
CONEXIONES

Plan eléctrico

Motor izquierdoControl A / BD6 / D9 (PWM)
Motor derechoControl A / BD10 / D11 (PWM)

PROGRAMACIÓN

Código Arduino completo

// ROBOT SEGUIDOR DE LÍNEA - ARDUINO NANO
// 3 SENSORES TCRT5000
// Derecho A0, medio A1, izquierdo A2
// Motor izquierdo D6 y D9
// Motor derecho D10 y D11

const byte SENSOR_DER = A0;
const byte SENSOR_MED = A1;
const byte SENSOR_IZQ = A2;

const byte MI_A = 6;
const byte MI_B = 9;
const byte MD_A = 10;
const byte MD_B = 11;

int velocidadRecta = 90;
int velocidadRapida = 130;
int velocidadLenta = 20;
int velocidadGiro = 120;

// LOW = línea negra. Si funciona al revés, usa HIGH.
const byte LINEA = LOW;

void setup() {
  pinMode(SENSOR_DER, INPUT);
  pinMode(SENSOR_MED, INPUT);
  pinMode(SENSOR_IZQ, INPUT);
  pinMode(MI_A, OUTPUT);
  pinMode(MI_B, OUTPUT);
  pinMode(MD_A, OUTPUT);
  pinMode(MD_B, OUTPUT);
  detener();
  delay(1000);
}

void loop() {
  bool izq = (digitalRead(SENSOR_IZQ) == LINEA);
  bool med = (digitalRead(SENSOR_MED) == LINEA);
  bool der = (digitalRead(SENSOR_DER) == LINEA);

  // 010: línea perfectamente al centro
  if (!izq && med && !der) {
    motores(velocidadRecta, velocidadRecta);
  }
  // 110: corregir rápidamente hacia la derecha
  else if (izq && med && !der) {
    motores(velocidadRapida, velocidadLenta);
  }
  // 100: giro fuerte hacia la derecha
  else if (izq && !med && !der) {
    motores(velocidadGiro, 20);
  }
  // 011: corregir rápidamente hacia la izquierda
  else if (!izq && med && der) {
    motores(velocidadLenta, velocidadRapida);
  }
  // 001: giro fuerte hacia la izquierda
  else if (!izq && !med && der) {
    motores(20, velocidadGiro);
  }
  // 111: cruce o línea gruesa
  else if (izq && med && der) {
    motores(velocidadRecta, velocidadRecta);
  }
  // 101: sensores laterales detectan la línea
  else if (izq && !med && der) {
    motores(velocidadRecta, velocidadRecta);
  }
  // 000: perdió la línea
  else {
    detener();
  }

  delay(1);
}

// Positivo = adelante. Negativo = atrás.
void motores(int izquierdo, int derecho) {
  if (izquierdo > 0) {
    analogWrite(MI_A, izquierdo);
    analogWrite(MI_B, 0);
  } else if (izquierdo < 0) {
    analogWrite(MI_A, 0);
    analogWrite(MI_B, -izquierdo);
  } else {
    analogWrite(MI_A, 0);
    analogWrite(MI_B, 0);
  }

  if (derecho > 0) {
    analogWrite(MD_A, derecho);
    analogWrite(MD_B, 0);
  } else if (derecho < 0) {
    analogWrite(MD_A, 0);
    analogWrite(MD_B, -derecho);
  } else {
    analogWrite(MD_A, 0);
    analogWrite(MD_B, 0);
  }
}

void detener() {
  motores(0, 0);
}

PRUEBA FINAL

Evaluación y errores frecuentes

  1. Lee cada sensor por separado en el monitor serial.
  2. Prueba los motores con el robot elevado.
  3. Ensaya primero sobre una pista recta.
  4. Agrega curvas y ajusta velocidad, altura y sensibilidad.
No distingue la línea

Ajusta altura, potenciómetros, iluminación y contraste de la pista.

Se sale en las curvas

Reduce velocidad, aumenta la corrección o cambia la separación de los sensores.

Corrige hacia el lado equivocado

Intercambia la lógica izquierda/derecha o verifica la orientación de motores.
